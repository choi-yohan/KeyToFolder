KeyToFolder for Windows (x64)

Extract the ZIP and double-click KeyToFolder.exe.
Python and Pillow are included. No separate Python installation is required.
Microsoft Edge WebView2 Runtime must be installed.
https://developer.microsoft.com/en-us/microsoft-edge/webview2/

Close the application window to stop the app and its local server.
Settings and undo history are stored at:
%APPDATA%\KeyToFolder\settings.json
Replacing the executable does not reset these settings.

The executable is not code-signed. Windows may ask you to confirm its publisher.
